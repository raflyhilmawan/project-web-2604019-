Tentang TechStarter Day

TechStarter Day adalah kegiatan pengenalan dunia pengembangan web untuk mahasiswa baru Teknologi Informasi.

Materi Praktik

Peserta belajar HTML, CSS, JavaScript, DevTools, dan Git.

Tujuan Kegiatan

Peserta mengenal cara developer menyusun informasi, menggunakan tools, membaca error, dan membangun sesuatu secara bertahap.

Cek Ketersediaan Kursi

Ingin mengikuti TechStarter Day 2026? Periksa ketersediaan kursi sebelum melakukan pendaftaran.

Masukkan jumlah kursi lalu tekan Cek Kursi.

Agenda

  1. Mengenal cara kerja halaman web
  2. Menyusun struktur HTML semantic
  3. Mencoba DevTools dan debugging
  4. Menyimpan checkpoint dengan Git

Apa yang Akan Dipelajari?

  • Membaca struktur halaman sebagai developer
  • Memilih tag berdasarkan makna konten.
  • Mendiagnosis link dan gambar yang gagal.
  • Menyimpan perkembangan projek dengan Git.
